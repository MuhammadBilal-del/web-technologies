The HTML DOM

The browser builds a tree from the page. document is the root of that tree. From it you can find an element and change its text, its attributes, or its style.

  • getElementById("id") — one element
  • querySelector("css selector") — the first match
  • querySelectorAll("css selector") — every match, as a list
