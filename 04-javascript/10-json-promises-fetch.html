JSON, promises, async/await, and fetch

JSON

JSON is text for storing and sending data. JSON.stringify turns an object into text. JSON.parse turns that text back into an object.


  


  
Promises

  
A promise is a value that arrives later. then runs when it succeeds. async and await write the same wait in a way that reads top to bottom. This one waits half a second. It does not call the network.
