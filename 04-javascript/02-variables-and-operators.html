Variables, data types, and operators

let is a variable you can assign again. const is a binding you cannot assign again. var is the older keyword. In this course, prefer let and const.

Common types: number, string, boolean, object, and undefined. An operator does work on values. == converts types before it compares. === does not. Use ===.
