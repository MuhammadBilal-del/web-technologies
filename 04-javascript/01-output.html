Where to put JavaScript, and how it writes output

JavaScript goes between <script> and </script>. You can put any number of scripts in the head or the body. A script at the end of the body runs after the elements exist, which is what we want when the code looks them up.

An external file is the same idea: <script src="script.js"></script>. The exercise in folder 05 uses that.

Four ways to show a value

  • innerHTML writes into an element. This is the usual way to show a result on the page.
  • window.alert() opens a dialog. Fine for a quick check, annoying on a real page.
  • console.log() writes to the browser console (F12). Use it while you are debugging.
  • document.write() writes into the page while it is loading. If you call it later, it wipes the page, so this demo does not call it.
