Width, with and without border-box

Both boxes set width: 200px, padding: 20px, and a 6px border.

  • content-box (the default): the width is only the content. Padding and border are added. Total width = 200 + 20 + 20 + 6 + 6 = 252px.
  • border-box: the width includes content, padding, and border. The box stays 200px.

Margin shorthand

margin: 8px 24px 8px 40px is top, right, bottom, left. Two values mean vertical, then horizontal. One value means all four sides. Padding uses the same shorthand.

This block uses a four-value margin. The left gap is the largest.
