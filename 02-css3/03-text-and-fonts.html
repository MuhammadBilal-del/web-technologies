Colors, text, and fonts

Set a color with a name, a hex value, rgb(), rgba() (the last number is opacity), or hsl(). Keep text and background far enough apart that the words stay readable.

color name: tomato
hex: #16324f
rgb(154, 52, 18)
rgba(22, 50, 79, 0.75)
hsl(210, 55%, 20%)

Font families

CSS has five generic families. On a screen, sans-serif is usually the easiest to read. The browser uses the first font in the list that is installed.

Serif — Georgia. Small strokes at the ends of letters.

Sans-serif — Arial. Clean lines.

Monospace — Consolas. Every letter has the same width.

Cursive — a handwriting face, if the computer has one.

font-weight: 700 and font-style: italic

font-size can be px, em, rem, or a percentage. This line is 0.85rem.
