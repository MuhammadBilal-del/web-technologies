Three ways to add CSS

A CSS rule is a selector plus declarations. Each declaration is a property, a colon, a value, and a semicolon.

Inline. The style attribute on this paragraph sets the color.

Internal. The class is defined in the style element in the head.

External. Color and padding come from external.css. The background was overridden by a later rule in the head.

Cascade

When more than one rule applies, the winner is usually:

  1. Inline style
  2. Internal and external style sheets (the one that appears last, if specificity is equal)
  3. The browser default

!important beats a normal rule, including a normal inline style. Use it rarely.

The style attribute says crimson. The stylesheet says navy with !important, so the text is navy.

Comments in CSS start with /* and end with */. HTML comments use <!-- -->. The browser ignores both.
