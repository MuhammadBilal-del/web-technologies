Display, position, float, and overflow

display

block starts on a new line. inline stays in the line. none removes the element from the layout. span is inline by default; here one of them is set to block.

inline inline display: block You cannot see this span. It is display: none.

The hidden span is still in the HTML. It takes no space.

position

static is the default. Top, right, bottom, and left do nothing until you change position.

position: relative; left: 30px. It moved from its normal place. The gap it left is still empty.
absolute
This stage is position: relative. The badge is position: absolute, so it is placed against the stage, not the page.

Scroll inside the box. The yellow bar is position: sticky with top: 0. It scrolls until it hits the top of the box, then it sticks.

CSS layout is display, position, float, and overflow.

Sticky sits between relative and fixed.

Fixed would stick to the browser window. There is a small fixed label at the bottom right of this page. It stays put while the page scrolls.

float and clear

The image is float: left. This text wraps beside it. float: right would pin it to the right. float: none is the default.

clear: both pushes this paragraph below the float.

overflow

overflow: auto — a scrollbar only if the text does not fit.

Short pages do not need a scrollbar. This box is 70px tall, so the rest of this sentence is reached by scrolling. Visible is the default and lets the text spill out. Hidden clips it. Scroll always shows a bar.

overflow: hidden — the extra text is clipped.

The second sentence is cut off because the box hides whatever does not fit inside its height.
