# 01 · HTML5

Weeks 1 and 2. HTML describes the **structure** of a page. It is a markup language, not a programming language.

The lecture starts with the web itself (Internet, WWW, HTTP, URL, browser, server), then tags, attributes, block and inline elements, lists, links, images, tables, forms, semantic tags, and audio/video.
