About this page

HTML5 added tags for regions we used to build with div. header is the title and the navigation. It is not the same as head, and it is not an h1.

nav is a block of links. main is the primary content. article can stand alone. section is a grouped part of the page. aside is related, but not the main text. footer holds the closing information. It is usually at the bottom, but it does not have to be.

Topics on this page

  • header and nav
  • main, article, section
  • aside and footer
