Images

img is an empty, inline element. src is the file path. alt is the text a browser shows if the file cannot be loaded, and the text a screen reader speaks. Always write alt.

A local image

width and height reserve space so the page does not jump when the image arrives. The path is relative: images/campus-mark.svg sits next to this folder.

Figure and caption

figure groups a picture with a caption. figcaption is the caption.

A missing file

Images often fail the first time: a wrong folder, a capital letter that does not match, or a space in the name. The alt text is what remains.
