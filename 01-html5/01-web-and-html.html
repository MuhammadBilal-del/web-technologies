What the web is, and a first HTML page

HTML stands for HyperText Markup Language. It describes the structure of a page. The browser reads the tags and paints the page.

A few words from lecture 1

Internet
A global network of networks. Computers on it can share information.
World Wide Web
The part of the Internet you browse: pages and other resources transferred with HTTP. Tim Berners-Lee invented the web; the W3C keeps its standards.
HTTP
HyperText Transfer Protocol. The rules a browser and a server follow when a page is requested.
URL
Uniform Resource Locator. The address of a resource. Shape: protocol://hostname/path. Example: https://www.ucp.edu.pk/.
Website and web page
A website is a collection of pages at one address. The first page is the home page. Each page is a document, usually written in HTML.
Browser and web server
The browser (Chrome, Firefox, Safari, Edge) is the client on your computer. The server is the computer that stores the site and is connected to the Internet. You ask, the server sends the files back.
DNS
The Domain Name System turns a name such as www.ucp.edu.pk into the numeric IP address of the server.

What happens when you open a page

  1. You type a URL.
  2. DNS returns an IP address.
  3. The browser sends an HTTP request to that server.
  4. The server returns the HTML, and then the images, CSS, and scripts the page asks for.
  5. The browser puts those files together and shows one page.

A minimal HTML5 document

Every page in this folder starts with a document type, then html, head, and body.

<!DOCTYPE html>
<html>
<head>
  <title>Page Title</title>
</head>
<body>
  <h1>Web Application Development</h1>
  <p>My first paragraph.</p>
</body>
</html>

Web Application Development

My first paragraph. This one is real: the browser rendered the tags above the box, and these two lines are the same kind of markup.
