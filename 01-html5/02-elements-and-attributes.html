Elements, attributes, and block vs inline

An element

An element is a start tag, some content, and an end tag:

<tagname>Content goes here...</tagname>

Attributes

Attributes add information. They go in the start tag, usually as name="value".

  • id — one element on the page. Used by CSS and JavaScript.
  • class — a group of elements that share a style.
  • style — CSS on a single element. It works, but a style sheet is easier to maintain.
  • title — extra text, often shown as a tooltip.

Block and inline

A block element starts on a new line and takes the width of its parent. A heading, a paragraph, and a div are block elements.

An inline element sits in the line and uses only as much width as it needs. span, a, and img are inline.

Empty elements have no end tag. <br> and <img> are empty elements. In HTML5 you write them without a slash.
