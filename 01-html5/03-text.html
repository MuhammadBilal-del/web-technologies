Headings, paragraphs, and text

Headings h1 to h6 are block elements. Use one h1 for the page title, then smaller headings for sections. A p holds a paragraph and should contain inline elements only.

h1 — Web Application Development

h2 — HTML5

h3 — Text

h4 — A smaller heading

h5 — Smaller still
h6 — The smallest heading

This is a paragraph. Browsers ignore extra spaces and line breaks in the source, so we use tags when we want a break.

Inline text

strong means important. b is bold without that meaning. Screen readers treat them differently.

em is emphasis. i is italic, often a term or a title: HTML and CSS by Jon Duckett.

mark highlights. H2O uses sub. E = mc2 uses sup.

small is a side comment, such as a copyright line.

A blockquote is a longer quotation, set apart from the paragraph.

A short quote sits in the line: tags describe structure.

A few character entities

Less than: <   Greater than: >   Ampersand: &   Copyright: ©

Write &lt; when you want the browser to show a tag instead of reading it as markup.
