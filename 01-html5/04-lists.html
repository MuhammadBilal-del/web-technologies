Lists

A list is a group of items. ul is unordered (bullets). ol is ordered (numbers). Each item is an li.

Unordered

  • HTML — structure
  • CSS — presentation
  • JavaScript — behaviour

Ordered

  1. Type a URL in the browser.
  2. DNS looks up the IP address.
  3. The server returns the page.

Nested

  • Front end
    • HTML5
    • CSS3
    • Bootstrap
  • Back end, later in the degree
    1. A server language
    2. A database
