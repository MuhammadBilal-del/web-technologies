Web Technologies

Web Application Development · CSSE3143 · Fall 2026

Muhammad Bilal · L1F22BSCS1040 · Instructor: M. Umar Hameed

Lab examples for the front-end part of the course: HTML5, CSS3, Bootstrap 5, and JavaScript. Each page is a small file you can read from top to bottom. The last item is the “Change the page with JavaScript” exercise.

01 · HTML5

Structure, text, lists, links, images, tables, forms, semantic tags, and media.

  • What the web is, and a first HTML page Internet, URL, document
  • Elements, attributes, and block vs inline tags, id, class
  • Headings, paragraphs, and text h1–h6, strong, em
  • Lists ul, ol, dl
  • Links absolute, relative, target
  • Images src, alt, figure
  • Tables th, td, colspan, rowspan
  • Forms and validation attributes input types, required
  • Semantic layout header, main, article
  • Audio and video controls, source

02 · CSS3

Syntax, selectors, text, the box model, layout, flexbox, and effects.

  • Three ways to add CSS inline, internal, external
  • Selectors element, class, id, pseudo
  • Colors, text, and fonts hex, rgb, font-family
  • The box model margin, border, padding
  • Backgrounds, links, lists, tables, navbar link states
  • Display, position, float, overflow static to sticky
  • Flexbox direction, wrap, justify
  • Radius, shadow, gradient, motion transition, animation

03 · Bootstrap 5

Loaded from the jsDelivr CDN. Grid, common components, and one combined page.

  • Containers container, container-fluid
  • Grid system 12 columns, breakpoints
  • Typography, colors, and spacing text-*, bg-*, m-*, p-*
  • Buttons and alerts btn, alert
  • Tables striped, hover
  • Forms form-control, checks
  • Navbar collapse on a small screen
  • Cards header, body, footer
  • Carousel slides and controls
  • A small page template navbar, grid, cards

04 · JavaScript

From variables and loops to the DOM, ES6, and fetch.

  • Where to put JavaScript, and output innerHTML, alert, console
  • Variables, data types, and operators let, const, ===
  • if, else, switch, and loops for, while
  • Functions and arrow functions parameters, return
  • Arrays and objects map, filter, reduce
  • ES6 features destructuring, spread, class
  • The DOM getElementById, style, classList
  • Events click, mouse, keyboard
  • Form validation check before submit
  • JSON, promises, and fetch async/await
  • Modules export and import

05 · Change the page with JavaScript

Marked exercise. The HTML and CSS are given. The script handles the four buttons.

  • Open the exercise text, color, hide/show, +1
