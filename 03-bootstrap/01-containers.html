Containers

A Bootstrap page needs the HTML5 doctype, the viewport meta tag, and the Bootstrap CSS file. A container pads the content and lines it up with the grid.

.container

Fixed width that changes at each breakpoint. It stays centered and does not touch the edges of a large screen.

.container-fluid

Full width of the viewport. Use it when the band should run edge to edge.

Resize the window. The light band grows until its breakpoint, then jumps. The blue band always spans the screen.
