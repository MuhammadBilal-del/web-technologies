# 03 · Bootstrap 5

Week 5. Bootstrap is a front-end framework: HTML, CSS, and JavaScript components for responsive, mobile-first pages. The grid is flexbox with 12 columns.

These pages load Bootstrap 5.3 from the jsDelivr CDN, the same approach as the lecture (the slides used 5.1.3). The class names in the slides still apply. You need a network connection for the styles and for the navbar and carousel scripts.

Every page sets the viewport:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```
